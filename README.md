# My Geodev-lab-project
GIS-Based Analysis and Mapping of Steep-Slope Terrain in Ibadan North Local Government Area, Oyo State.

 This project is being built over twelve months with GeoDev Lab Africa, Cohort One.

## Project Overview

This project uses GIS and elevation (DEM) data to identify and map out areas with steep slopes in Ibadan North LGA, Oyo State. The analysis will show where steep terrain is located and how it is spread across the area. The results can help support better land-use planning, safer development, and environmental management, especially in areas where steep slopes may increase the risk of erosion and surface runoff.
